# Курсовой проект по модулю BD
Проект, который получает информацию о вакансиях с платформы hh.ru в России, сохраняет их в базу данных и позволяет управлять данными из бд

## Описание проекта
В проекте реализованны классы для поиска по api вакансий, также сохранения в базу данных В директории "data" лежит файл "companies.json" который хранит 10 компаний для поиска их вакансий его можно дополнять вручную либо из самой программы
